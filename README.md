## تراز چیست و چرا ساخته شده است؟

گاهی پاسخ خوبی از ChatGPT یا Claude می‌گیری، آن را در Word یا PowerPoint کپی می‌کنی، اما با متنی به‌هم‌ریخته روبه‌رو می‌شوی. جمله‌های دوزبانه درست نمایش داده نمی‌شوند، فاصله‌گذاری کلمات فارسی به‌هم می‌ریزد، پرانتزها جابه‌جا می‌شوند و فرمول‌های LaTeX به شکل کد خام در میان متن باقی می‌مانند.

تراز برای حل همین مشکلات ساخته شده است؛ ابتدا برای استفاده شخصی در نوشتن پایان‌نامه و مقاله‌های فنی، و سپس برای همه کسانی که با متن‌های فارسی، اصطلاحات انگلیسی و فرمول‌های ریاضی سروکار دارند.

**متن را وارد کن، نتیجه را بررسی کن و با یک کلیک آن را برای استفاده در Word یا PowerPoint آماده کن.**

## امکانات اصلی

**🧭 اصلاح جهت و ترتیب متن‌های دوزبانه**

جهت پاراگراف‌ها و بخش‌های انگلیسی را مدیریت می‌کند تا ترتیب منطقی جمله‌ها حفظ شود و ترکیب متن فارسی و انگلیسی به‌هم نریزد.

**🧹 پاک‌سازی نویسه‌های نامرئی**

کاراکترهای پنهانی را که ممکن است هنگام انتقال متن از چت‌بات‌ها وارد شوند و در Word یا PowerPoint به شکل مربع‌های خالی نمایش داده شوند، شناسایی و حذف می‌کند.

**✍️ مدیریت نیم‌فاصله**

نیم‌فاصله را در ترکیب‌های رایج فارسی مانند «می‌روم»، «کتاب‌ها» و «بهره‌برداری» اصلاح می‌کند. فهرست استثناهای قابل تنظیم نیز برای موارد خاص در نظر گرفته شده است.

**🔢 تنظیم شیوه نمایش اعداد**

امکان نمایش اعداد به فارسی، انگلیسی یا بدون تغییر را فراهم می‌کند. این تنظیمات را می‌توان برای متن، عنوان، جدول، فهرست و عبارت‌های فنی به صورت جداگانه انتخاب کرد. شناسه‌هایی مانند `IEEE 1547`، نشانی‌های وب و مسیر فایل‌ها نیز حفظ می‌شوند.

**❝ اصلاح نشانه‌گذاری فارسی**

فاصله‌گذاری و کاربرد علائم نگارشی، از جمله ویرگول، نقطه‌ویرگول، علامت سؤال، پرانتز، گیومه، سه‌نقطه، درصد و خط تیره را مرتب می‌کند.

**∑ تبدیل فرمول‌های LaTeX به معادله Word**

فرمول‌ها را به معادله‌های بومی Word با قالب OMML تبدیل می‌کند؛ بدون اینکه خروجی صرفاً یک تصویر یا متن خام باشد. امکان دریافت فرمول به صورت متن خطی ساده نیز وجود دارد.

**📝 تبدیل Markdown به ساختار قابل استفاده در Word**

عنوان‌ها، فهرست‌ها، جدول‌ها، نقل‌قول‌ها، کدها و پیوندها را به ساختارهای متناظر در سند Word تبدیل می‌کند.

**📤 خروجی در قالب‌های مختلف**

متن پردازش‌شده را مستقیماً برای Word و PowerPoint کپی کن یا آن را در قالب‌های زیر دریافت کن:

- `.docx`
- `.html`
- `.md`
- `.txt`

**🎛️ پیش‌تنظیم‌های متناسب با کاربردهای مختلف**

تنظیمات آماده برای پایان‌نامه، گزارش فنی، اسلاید، ایمیل، چت و حالت «حداقل تغییر» در دسترس هستند تا بتوانی متناسب با نوع متن، شیوه پردازش را انتخاب کنی.

**🔍 بررسی تغییرات پیش از دریافت خروجی**

با استفاده از نمای مقایسه تغییرات، نمایش جهت بخش‌های متن و گزارش ایمنی آفیس می‌توانی نتیجه پردازش را پیش از کپی یا دانلود بررسی کنی.

## چطور از تراز استفاده کنم؟

استفاده از برنامه ساده است:

1. **متن را وارد کن:** محتوای مورد نظرت را در بخش ورودی قرار بده.
2. **نتیجه را بررسی کن:** خروجی پردازش‌شده در پیش‌نمایش نمایش داده می‌شود. در صورت نیاز، تنظیمات را تغییر بده.
3. **خروجی را دریافت کن:** روی دکمه «پردازش و کپی» کلیک کن یا از میان‌بر `Ctrl + Enter` استفاده کن. سپس متن را با `Ctrl + V` در Word یا برنامه مورد نظرت قرار بده.

### اجرای برنامه روی کامپیوتر

نیازی به نصب برنامه یا راه‌اندازی سرور نیست.

1. مخزن را از GitHub دانلود کن. برای این کار روی دکمه سبز **Code** و سپس **Download ZIP** کلیک کن.

   همچنین می‌توانی مخزن را با Git دریافت کنی:

   ```bash
   git clone https://github.com/njt138/Taraz.git
   ```

2. فایل `TARAZ.html` را با مرورگر Chrome یا Edge باز کن.

همین! برنامه آماده استفاده است.

## اینترنت و حریم خصوصی

**پردازش متن به صورت محلی و در مرورگر خودت انجام می‌شود.** طبق طراحی برنامه، متن واردشده ذخیره یا به سرور ارسال نمی‌شود و فقط تنظیمات انتخابی در حافظه مرورگر باقی می‌مانند.

با این حال، برخی کتابخانه‌ها و منابع رابط کاربری از اینترنت بارگذاری می‌شوند:

| منبع | کاربرد | وضعیت در نبود اینترنت |
|---|---|---|
| Google Fonts | بارگذاری قلم‌های رابط کاربری، مانند Vazirmatn | قلم‌های نصب‌شده روی سیستم جایگزین می‌شوند. |
| KaTeX | نمایش فرمول‌ها در پیش‌نمایش | فرمول‌ها به شکل کد LaTeX نمایش داده می‌شوند. |
| docx و JSZip | ساخت فایل‌های Word | دانلود فایل `.docx` کار نمی‌کند؛ اما کپی متن برای Word و سایر خروجی‌ها در دسترس است. |

بارگذاری این منابع، نشانی IP را در اختیار سرویس ارائه‌دهنده قرار می‌دهد؛ اما طبق طراحی برنامه، متن واردشده به آن سرویس‌ها ارسال نمی‌شود.

## محدودیت‌های فعلی

تراز هنوز در نسخه اولیه خود قرار دارد و چند محدودیت آن عبارت‌اند از:

- **مرورگرها:** برنامه برای Chrome و Edge طراحی شده است و عملکرد آن در مرورگرهای دیگر به طور کامل آزمایش نشده است.
- **سازگاری فرمول‌ها:** معادله‌ها برای Microsoft Word تولید می‌شوند. ممکن است LibreOffice و Google Docs آن‌ها را متفاوت نمایش دهند یا از برخی قابلیت‌ها پشتیبانی نکنند.
- **اعداد اعشاری:** جداکننده اعشاری به طور پیش‌فرض نقطه (`.`) است. در صورت نیاز می‌توان آن را از تنظیمات تغییر داد.
- **خط تیره در دستورات فنی:** تبدیل `--` به خط تیره ممکن است روی آرگومان‌های خط فرمان، مانند `--verbose`، اثر بگذارد. برای حفظ این عبارت‌ها، بهتر است آن‌ها را داخل بک‌تیک قرار بدهی؛ برای مثال، `--verbose`.

اگر با مشکلی روبه‌رو شدی یا پیشنهادی برای بهبود برنامه داری، می‌توانی آن را از طریق بخش Issues مخزن ثبت کنی.

## گزارش اشکال و پیشنهاد

برای گزارش مشکل یا پیشنهاد قابلیت جدید، یک موضوع تازه در بخش **Issues** همین مخزن ایجاد کن و این موارد را توضیح بده:

- متن ورودی چه بوده است؛ در صورت نداشتن اطلاعات خصوصی، نمونه‌ای از آن را نیز قرار بده.
- برنامه چه خروجی‌ای تولید کرده است.
- انتظار داشتی چه نتیجه‌ای دریافت کنی.

گزارش‌های دقیق، بازتولید و رفع مشکلات را آسان‌تر می‌کنند و به بهبود تراز کمک خواهند کرد.

## ساختار پروژه

ساختار اصلی فایل‌های پروژه به این صورت است:

```text
TARAZ.html        نقطه ورود برنامه
css/              فایل‌های سبک و ظاهر رابط کاربری
js/core/          ثبت ماژول‌ها، تنظیمات و ترجمه‌ها
js/engine/        موتور پردازش متن، جهت، نیم‌فاصله، ارقام و نشانه‌گذاری
js/math/          تشخیص و پاک‌سازی فرمول‌های LaTeX
js/output/        مدیریت خروجی‌ها، کلیپ‌بورد، DOCX، OMML و HTML
js/ui/            اجزای رابط کاربری
```

این پروژه بدون npm، فریم‌ورک یا ابزار ساخت اجرا می‌شود و بر پایه HTML، CSS و JavaScript ساده توسعه یافته است.
